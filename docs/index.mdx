## One policy, four steps

**Validate → Resolve company and owner → Match a rule → Commit an assignment**

Rules run in the order you define. Assign to an existing owner, a named person, or
an eligible member of a round-robin pool. Every result carries a rule trace and
provider facts. A stable idempotency key makes retries return the original assignment.
