Create a router with two people and a round-robin pool. This example runs locally
without CRM credentials or network requests.

## 1. Set up the SDK

Requires Node.js 22 or later and pnpm 10.20.0. Until packages are published, run the example
from a checkout of this repository:

```sh
git clone https://github.com/domeccleston/routing-sdk.git
cd routing-sdk
pnpm install
pnpm build
```

## 2. Configure and assign

Create `examples/round-robin/first-assignment.ts` in its workspace. The example uses illustrative
booking URLs; replace them with your own before sending visitors to them.

```ts
import { createRouter } from "open-routing";
const router = createRouter({
  schema: { workEmail: { type: "email", required: true, privacy: "mask" } },
  people: {
    alex: { name: "Alex", bookingUrl: "https://calendar.example/alex" },
    sam: { name: "Sam", bookingUrl: "https://calendar.example/sam" },
  },
  pools: {
    sales: { members: ["alex", "sam"] },
  },
  rules: [{ id: "new-sales-lead", assign: { pool: "sales" } }],
  fallback: { redirect: "/thanks" },
  database: ":memory:",
});

try {
  const lead = router.parse({ workEmail: "buyer@acme.example" });
  const first = await router.assign(lead, { idempotencyKey: "lead-001" });
  const retry = await router.assign(lead, { idempotencyKey: "lead-001" });
  const next = await router.assign(lead, { idempotencyKey: "lead-002" });

  console.log(first.outcome, first.personId); // assigned alex
  console.log(first.id === retry.id); // true: same lead, same assignment
  console.log(next.personId); // sam: a new lead advances the pool
} finally {
  await router.close();
}
```

Omitting `when` matches every validated input. Place this catch-all rule last
when you add more specific rules.

## 3. Run it

```sh
pnpm --filter @open-routing/example-round-robin exec tsx first-assignment.ts
```

Expected output:

```text
assigned alex
true
sam
```

This example starts with a fresh in-memory store every time. For persistence across
process restarts, omit `database` to use `.data/routing.sqlite`, or provide your own path. Reusing a key
returns its saved result even if the input or rules have since changed.

## 4. Connect your application

Use `result.redirectUrl` as the destination for your host application's redirect.
An `assigned` result identifies a person; an `unassigned` result directs the visitor
to your fallback or a rule-specific page. Assignment does not confirm a booked meeting.
