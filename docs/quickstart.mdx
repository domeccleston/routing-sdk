## Requirements

Use Node.js 22 or newer and npm. These instructions run the SDK from its workspace
in this repository.

## Start the example

```sh
git clone https://github.com/domeccleston/routing-sdk.git
cd routing-sdk
npm install
npm run dev
```

Open [the contact-sales form](http://localhost:3000), choose a preset or enter form
values, and submit it. The server validates the input, resolves fixture provider
data, applies the routing configuration, and issues a `303` redirect to a calendar
or the success page.

The example uses fixture enrichment and ownership by default; no Attio API key is
required. Demo representatives currently share one Cal.com booking URL.

## Inspect the result

Open [the local dashboard](http://localhost:3000/admin) to see submissions, decision
snapshots, provider data, and evaluated rules. Submissions are persisted in
`examples/contact-sales/.data/routing.sqlite`.

A completed submission means routing finished, not that a meeting was booked.
Read [the record model](/decision-records) before using the store or exposing the
dashboard beyond your machine.

## Customize routing

The example configuration lives in `examples/contact-sales/router.config.ts`.
It defines the form schema and connects providers, people, round-robin pools,
ordered rules, an assignment store, and a fallback redirect to `createRouter`.

| Location                                               | What to change                                             |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| `examples/contact-sales/router.config.ts`              | Typed form schema, ordered rules, and router configuration |
| `examples/contact-sales/fixtures/routing/`             | Representative and territory fixtures                      |
| `examples/contact-sales/fixtures/attio/`               | Deterministic provider data                                |
| `examples/contact-sales/fixtures/routing/scenarios.ts` | Presets and expected routing decisions                     |

## Check your changes

```sh
npm test
npm run typecheck
```

Default tests make no network requests. Run `npm run check` for the full code
quality suite.
